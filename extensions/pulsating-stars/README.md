# Pulsating stars

A course-pack extension: three lessons Gravitas already has, in order, with
notes for the teacher and the student in English and Spanish. It ends on a
real light curve, SU Draconis (`extensions/su-dra-tess-s15`), which a class
installs from the catalog and opens in the observatory.

```bash
npm run sdk -- validate extensions/pulsating-stars
npm run sdk -- test extensions/pulsating-stars
npm run sdk -- pack extensions/pulsating-stars
```

The course format can name only lessons, so the last note names the data
pack in words. CATALOG.md records that as a gap in the SDK.
