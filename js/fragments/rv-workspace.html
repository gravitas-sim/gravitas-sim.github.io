Uncertainty analysis (optional)

Simulates this observing run again and again — the same epochs, the same stated uncertainties, a fresh noise draw each time — and refits every one with the search you just ran.

The same seed reproduces the same intervals exactly, and the export carries it.

A circular single-planet model: period, amplitude, phase and systemic velocity, and nothing else. When it does not fit, the residuals will show a shape rather than absorbing the problem into a parameter — which is the reason for keeping the model this restrictive. The lowest point on the periodogram is not an answer: on sparsely sampled data several periods routinely fit equally well, and the ones that do are listed beneath it.
