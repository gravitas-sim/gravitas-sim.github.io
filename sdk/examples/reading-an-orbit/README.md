# Reading an orbit

An investigation-pack extension: `gravitas.investigation-pack/1`, a guided
investigation of Kepler's third law as data, with a held prediction, a
measurement, a question drawn from a bank and a remediation step, in English and
Spanish. It is the Studio composer's own example, written by
`npm run sdk -- init investigation-pack reading-an-orbit`.

`npm run sdk -- validate sdk/examples/reading-an-orbit`
