# Finding exoplanets

An example **course-pack** extension for the Gravitas Extension SDK
([sdk/README.md](../../README.md)): five lessons Gravitas already has, in
three units, with notes for the teacher and the student, in English and
Spanish.

A course pack is content only: lesson ids, text and order. Gravitas does not
read course packs at run time yet. The SDK validates, tests and archives one
in the format the course-pack builder will read.

```bash
npm run sdk -- inspect sdk/examples/finding-exoplanets --preview
```
