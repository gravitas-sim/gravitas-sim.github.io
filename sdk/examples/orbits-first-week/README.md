# Orbits: a first week

A course-pack extension in the form the course-pack builder writes,
`gravitas.course-pack/2`: one unit of five items (a reading, a scenario and
three investigations), with objectives, minutes, an optional path, and a pin on
each lesson it names, so the pack says which version of each it was made with.
It is an `exact` pack: every lesson is pinned, and `sdk validate` warns when a
pinned lesson has since changed.

`npm run sdk -- validate sdk/examples/orbits-first-week`
